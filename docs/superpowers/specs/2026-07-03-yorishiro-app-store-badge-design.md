# Yorishiro App Store Badge Design

## Goal

Replace the custom App Store call-to-action on the Yorishiro landing page with Apple's supplied Japanese App Store badge and remove the duplicated App Store information card.

## Scope

- Replace the hero `App Storeで見る` text button with the supplied Apple badge embed.
- Use the supplied App Store URL, campaign parameters, badge image URL, alternative text, and dimensions without modification.
- Remove the featured App Store card from the link grid.
- Keep the privacy policy, terms, and support cards unchanged.

## Layout

The badge remains inside the existing hero action area and is the page's only App Store download call-to-action. Existing responsive layout and spacing are retained unless visual verification shows clipping or overflow.

## Accessibility And Behavior

- The badge image keeps the supplied `App Storeでダウンロード` alternative text.
- The link follows the supplied embed behavior.
- The badge must remain fully visible without horizontal overflow on desktop and mobile viewports.

## Verification

- Confirm the old `App Storeで見る` text button is absent.
- Confirm the featured App Store card is absent.
- Confirm the official badge image and destination URL are present.
- Verify desktop and mobile rendering for clipping, overlap, and horizontal overflow.

プライバシーポリシー

最終更新日：2026年11月14日

横田裕市（以下「当方」）は、Chrome拡張「Xブックマークエクスポーター」と本紹介サイトで取り扱う情報について、以下のとおり説明します。本拡張はXの非公式ツールです。投稿の取得・保存は利用者の端末で行い、任意の購入・復元にはCloudflare、Resend、Stripeを利用します。

1. ブラウザ内で取り扱う投稿・履歴情報

利用者が拡張の開始ボタンを押したときに、XのBookmarks通信を利用して取得します。通常のX閲覧だけでは取得を開始しません。投稿ID・URL・日時・本文、作者のID・ユーザー名・表示名・プロフィール画像URL、引用・再投稿の本文・作者・ID・日時、返信先ID、URL展開情報、添付の画像・GIF・動画のURL・種類・所属投稿・alt・形式候補等を扱います。

これらを取得日時・状態とともに、このChromeプロファイルの拡張専用IndexedDBへ保存します。目的は投稿の保存、履歴の表示、CSV・JSON・Excel・投稿アーカイブの生成です。ブックマークした日時が応答にない場合は推測して補いません。

Xページ内でログイン中の数値アカウントIDをtwid Cookieから取り出し、履歴の分離と取得中のアカウント一致確認に使います。数値アカウントID、確認状態、全件・差分の取得方法、基準履歴ID、追加投稿ID、照合件数、完了日時、終了理由を端末内に保存します。投稿者のIDとは区別し、課金サービスへ送信しません。

全件・差分の次回設定、1〜50GB（既定5GB）のZIP分割設定をchrome.storage.localへ保存します。取得ジョブはそれぞれ独立した投稿データを持ち、削除同期や別端末へのデータ同期は行いません。

2. Xへの通信と認証情報

追加取得には、Xページが実際に送ったBookmarks通信の認証ヘッダーとログインセッションを利用します。拡張は、利用者が開始ボタンを押したタブに限り、取得が始まるまでの間だけ、ブラウザのwebRequest APIでXのBookmarks通信のURLと authorization・content-type・x-* ヘッダーを観測します。Cookieは読み取りません。これらはXと同じ要求を繰り返すために、ブラウザ内の一時メモリでそのXタブへ渡すだけで、拡張の保存領域、出力ファイル、診断ログ、開発者の課金サービスへ記録・送信しません。開始許可はタブに結び付けた短期・一回限りの許可としてchrome.storage.sessionで管理します。

新しい版の確認は、Chrome標準のChrome Web Store更新の仕組みを使います。開発者のサーバーへは何も送信しません。

3. メディアの容量調査と保存

静止画像はpbs.twimg.com、動画・GIFのMP4はvideo.twimg.comから取得します。CDNへの要求にログインCookieを付けません。利用者が必要なCDNアクセスを許可済みの場合、結果画面の表示・保存データの選択時にHEAD、必要に応じてRange要求で容量を自動調査します。容量調査のために本文全体をダウンロードしません。未許可時は利用者の操作で権限を要求します。

メディア本文は利用者が保存を開始したときに取得します。同じ応答に含まれる引用・再投稿の添付も対象にし、動画は最大ビットレートのMP4、GIFもMP4で保存します。Xと各CDNは通信先として要求を受け取ります。メディアのバイナリをIndexedDBへ永続保存しません。

投稿アーカイブは利用者が選択したフォルダの新規サブフォルダへ保存します。ZIP、archive.json、manifest.json、index.htmlには投稿・引用とメディアの対応が含まれます。保存先のハンドルを永続保存しません。オフラインHTMLは同梱データと展開済みローカルメディアを利用し、自動で外部通信しません。一般のダウンロード履歴は読み取りません。

4. 診断ログ

不具合の識別のため、取得の処理段階、固定エラーコード、HTTP状態、試行回数、ページ・項目の位置、件数、既知フィールドの型と未知フィールド数を、取得データに付随して端末内に保存します。直近200イベント、診断JSON全体256KiBまでに制限します。本文、投稿・ユーザーID、URL、Cookie、ヘッダー、メール、コード、token、生応答、任意の例外メッセージは含めません。

診断JSONの保存は利用者の操作で行い、自動アップロードはしません。サーバー側の外部サービス障害診断は固定イベント名・HTTPステータス・許可した例外分類と判別用真偽値だけを記録し、送信内容や認証値はログに出しません。

5. 任意の購入・復元と外部サービス

無料保存は認証や課金APIへの通信なしで利用できます。購入・復元を利用するときは、以下のサービスが機能提供の目的で情報を取り扱います。投稿本文、投稿者情報、メディアURL、取得アカウントの数値アカウントIDは課金サービスへ送りません。

  • Cloudflare Workers / D1：メールアドレス、メール確認コード、認証Bearer tokenをHTTPSで受け取ります。D1にはユーザーUUID、平文メール、コードのHMAC、30日セッションtokenのSHA-256 hash、送信制限用のメール・IPのHMAC、購入試行UUID、購入・決済ID、停止理由を保存します。コードとtokenの平文はD1へ保存しません。
  • Resend：確認メールを送るために、送信先メールアドレスと確認コードを渡します。
  • Stripe：決済と購入確認のために、メールアドレスとサーバーが生成したユーザー・購入試行UUIDを渡します。カード情報はStripeの決済画面で直接Stripeに入力され、当方はカード番号全体やCVCを保存しません。

確認コードは20分・5回まで・一度だけ有効で、再送すると以前のコードは無効になります。セッション期限は30日です。拡張のセッションはchrome.storage.localの信頼された拡張コンテキストに限定して保存し、Xページへ渡しません。サインアウトは現在のセッションだけを失効させ、購入記録は維持します。購入権限は署名付き通知とStripe APIでの支払い確認を経た記録で判定します。

各サービスの取り扱いは、Cloudflareのプライバシーポリシー、Resendのプライバシーポリシー、Stripeのプライバシーポリシーもご確認ください。

6. 保持・削除

端末内の取得データは、利用者が保存結果の一覧で選択して削除するまで保持します。画面閉鎖、再起動、拡張更新、ファイル出力後も再利用できます。削除した取得データの投稿・引用・添付情報・診断をまとめて削除し、他の履歴や設定は保持します。拡張のアンインストールやChromeプロファイルの削除時には保存領域も削除されます。エクスポート済みファイルは残るため、利用者自身で管理・削除してください。

サーバー上のコードやセッションは有効期限で利用を拒否します。有効期限と物理削除の時点は別であり、期限到達時の即時自動削除は保証しません。購入・復元の記録は、権利確認・復元・不正防止に必要な間保持します。情報の削除に関するご相談はmain@yokoichi.jpへお寄せください。

7. 第三者提供とサイトのアクセス情報

機能提供に必要な上記サービスへの送信を行います。情報を第三者へ販売したり、広告追跡に利用したりしません。拡張に広告・解析SDKや外部の実行コードの読み込みはありません。

この紹介サイトはGitHub Pagesで配信します。当方独自のアクセス解析は設置していませんが、ホスティング提供者がサービス提供・保護のためにIPアドレス等のアクセス情報を取り扱う場合があります。詳しくはGitHubのプライバシーステートメントをご確認ください。
